# Supply Chain & Inventory Performance Analytics

End-to-end Data Analyst portfolio project using Python, MySQL and Power BI.

## Dataset
Synthetic but realistic retail supply-chain data covering products, suppliers, warehouses, inventory, customer orders and supplier purchase orders.

## Main workflow
Raw CSVs -> Python data quality/cleaning -> MySQL analysis -> statistical analysis -> Power BI dashboard -> business insights.

## Data quality issues intentionally included
- Missing values
- Duplicate order records
- Negative quantities/prices
- Stockouts
- Excess inventory
- Delivery delays
- Supplier defects

## Recommended tools
VS Code, Python, MySQL Workbench/MySQL Server, Power BI Desktop.
